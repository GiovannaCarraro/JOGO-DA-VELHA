# ✨ Jogo da Velha (Tic-Tac-Toe) — Projeto React

Olá! Seja muito bem-vindo(a) ao repositório do **Jogo da Velha**! 🎮  
Este projeto é a evolução do clássico jogo da velha, construído com foco em boas práticas do desenvolvimento web front-end para o Projeto Final do curso **Técnico em Desenvolvimento de Sistemas**.

---

## 🎯 Objetivo do Projeto

O objetivo principal desta aplicação é refatorar e aprimorar a versão original do tutorial do React, aplicando padrões modernos do mercado:

* 🧩 **Componentização inteligente e reutilizável**
* 🎨 **Estilização modular** com CSS Modules e metodologia BEM
* 📱 **Layout responsivo** e limpo com auxílio do Bootstrap
* ⚡ **Performance e agilidade** com React e Vite
* 🧹 **Clean Code** e organização clara de pastas e responsabilidades

---

## 🛠️ Tecnologias e Linguagens Utilizadas

* **HTML5:** Estrutura semântica e acessível.
* **CSS3 / CSS Modules:** Estilização escopada e modularizada.
* **JavaScript (ES6+):** Lógica da aplicação e manipulação imutável do estado.
* **React:** Biblioteca para criação da interface baseada em componentes.
* **Vite:** Ferramenta de *build* e servidor de desenvolvimento ultra-rápido.
* **Bootstrap:** Framework estrutural para layout responsivo.
